# Verde Ember — Restaurant website (React + Vite)

## Run
```
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Customize
- Name, menu, prices, reviews, FAQ: `src/data.js`
- Images: `IMG` in `src/data.js` (replace with your own photos in /public)
- Colors: CSS variables at top of `src/styles.css`
- Sections: `src/sections.jsx`
